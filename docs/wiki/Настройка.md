# Настройка

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `HOME_VERSION` | `latest` | Версия образа `ghcr.io/sbrw-evc/home` (только для `docker-compose.yml`) |
| `HOME_PORT` | `8088` | Порт на хосте (только для `docker-compose.yml`) |
| `NPM_DATA_DIR` | `./npm-data` | Каталог `data` локального NPM (только для `docker-compose.yml`) |
| `BAO_ADDR` | — | Адрес OpenBao, например `http://openbao:8200` |
| `BAO_TOKEN` | — | Токен OpenBao |
| `BAO_ROLE_ID`, `BAO_SECRET_ID` | — | Вход через AppRole (вместо токена) |
| `BAO_KV_MOUNT` | `secret` | Точка монтирования KV v2 |
| `BAO_PATH_PREFIX` | `npm-dashboard/sources` | Где хранить учётные данные источников |
| `BAO_ADMIN_PATH` | `npm-dashboard/admin` | Где лежит пароль администратора |
| `BAO_NAMESPACE` | — | Пространство имён OpenBao |
| `BAO_SKIP_VERIFY` | `false` | Не проверять TLS-сертификат OpenBao |
| `ADMIN_PASSWORD` | — | Пароль администратора; если задан, важнее значения из OpenBao и не меняется из интерфейса |
| `TITLE` | `Мои сервисы` | Заголовок при первом запуске |
| `POLL_SECONDS` | `2` | Как часто проверять изменения локальной базы |
| `API_POLL_SECONDS` | `30` | Как часто опрашивать удалённые NPM (можно задать для каждого источника) |
| `ICON_TTL_HOURS` | `24` | Сколько хранить найденные иконки |
| `CONFIG` | `/config/config.json` | Файл настроек внутри контейнера |
| `NPM_DB` | `/npm/database.sqlite` | Путь к локальной базе по умолчанию |
| `PORT` | `8088` | Порт внутри контейнера |

## Настройки в интерфейсе

Страница **Настройки** (`#/settings`, нужен пароль администратора):

- **Общие** — заголовок, поисковик по умолчанию, показ выключенных хостов NPM, свои поисковые системы
  (адрес с `%s` вместо запроса, например `https://github.com/search?q=%s`).
- **Безопасность** — смена пароля администратора, выход. См. [[Безопасность]].
- **Источники NPM** — см. [[Источники NPM|Источники-NPM]].
- **Свои сайты** — список с редактированием.

## Файл config.json

Хранится в `./config/config.json` и редактируется приложением. Паролей в нём нет.

```json
{
  "title": "Мои сервисы",
  "show_disabled": true,
  "search": { "engine": "google", "custom": [{ "id": "gh", "name": "GitHub", "url": "https://github.com/search?q=%s" }] },
  "sources": [
    { "id": "local", "name": "Локальный NPM", "type": "sqlite", "path": "/npm/database.sqlite", "enabled": true },
    { "id": "a1b2c3d4", "name": "VPS", "type": "api", "url": "https://npm.example.com", "verify_tls": true, "poll_seconds": 30, "enabled": true }
  ],
  "sites": [{ "id": "e5f6", "name": "Роутер", "url": "http://192.168.0.1", "group": "Сеть", "description": "", "icon": "" }],
  "favorites": ["local:1", "custom:e5f6"]
}
```

Рядом лежит каталог `icons/` — кэш иконок сайтов. Его можно удалить: иконки найдутся заново.

## Резервная копия

Достаточно сохранить `./config` и данные OpenBao (`openbao/data` + ключ распечатки).
