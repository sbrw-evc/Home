# Источники NPM

Home показывает прокси-хосты (`Proxy Hosts`) из одного или нескольких Nginx Proxy Manager. Источники настраиваются
в **Настройки → Источники NPM**; кнопка **Проверить** проверяет подключение без сохранения.

## Локальная база (SQLite)

NPM по умолчанию хранит данные в `data/database.sqlite`. Смонтируйте каталог `data` в контейнер Home только на чтение:

```yaml
volumes:
  - /path/to/npm/data:/npm:ro
```

- Файл открывается в режиме только для чтения (`mode=ro`), Home ничего не меняет в NPM.
- Изменения подхватываются по времени изменения файла (раз в `POLL_SECONDS`).
- Из таблицы `proxy_host` читаются только домены, адрес назначения, статус, сертификат и список доступа.
  Поле `meta` — где NPM хранит ключи DNS-провайдеров — **не читается**.
- Работает только с SQLite. NPM с MySQL/MariaDB подключайте как удалённый источник через API.

## Удалённый NPM (API)

Для NPM на другом сервере или в интернете:

| Поле | Описание |
|---|---|
| Адрес NPM | Адрес админки, например `https://npm.example.com` или `http://10.0.0.5:81` |
| Логин, пароль | Учётная запись NPM. Сохраняются **только в OpenBao**, см. [[OpenBao]] |
| Опрос, сек | Как часто запрашивать список хостов (минимум 5) |
| Проверять TLS | Снимите для самоподписанного сертификата |

Home получает токен через `POST /api/tokens` и читает `GET /api/nginx/proxy-hosts`. Токен кэшируется и обновляется
сам. Рекомендуется отдельная учётная запись NPM с правами только на просмотр прокси-хостов.

> Если NPM не выдаёт токен по логину и паролю (например, у учётной записи включена двухфакторная аутентификация), источник покажет ошибку — используйте отдельную учётную запись без 2FA.

Пустое поле пароля при сохранении означает «оставить сохранённый». При удалении источника его секрет удаляется из OpenBao.

## Что показывается на карточке

| Поле NPM | На карточке |
|---|---|
| Первый домен без `*` | Название (поддомен) и ссылка |
| Остальные домены | Дополнительные строки |
| `forward_scheme://forward_host:forward_port` | Адрес назначения |
| Сертификат | HTTPS или HTTP; ссылка ведёт на `https://`, если сертификат есть |
| Список доступа | Бейдж ACL |
| Выключен | Карточка полупрозрачная (скрывается настройкой) |

Группы в меню — родительский домен (`got-it.evcsbrw.ru` для `ldap.got-it.evcsbrw.ru`).
Если источников несколько, в меню появляется раздел «Источники», а на карточках — бейдж источника.
