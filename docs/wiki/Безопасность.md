# Безопасность

## Что доступно без пароля

Без входа можно **смотреть** страницу: карточки, поиск, статус источников. Всё, что меняет данные, требует пароль
администратора: настройки, источники, свои сайты, избранное, смена пароля.

> Если пароль не задан ни в OpenBao, ни в `ADMIN_PASSWORD`, менять всё может любой, кто открыл страницу.
> В карточке **Безопасность** будет предупреждение.

## Пароль администратора

- Хранится в OpenBao (`secret/npm-dashboard/admin`) или в переменной `ADMIN_PASSWORD` — переменная важнее.
- Меняется в **Настройки → Безопасность**: текущий пароль, новый (минимум 8 символов) и повтор. Есть генератор и индикатор надёжности.
  Новый пароль действует сразу, старый перестаёт работать.
- Если пароль задан через `ADMIN_PASSWORD`, его можно сменить только в `.env`.
- Неверный пароль отвечает с задержкой в 1 секунду — это замедляет перебор.
- Браузер хранит пароль до закрытия вкладки (`sessionStorage`). Кнопка **Выйти** удаляет его сразу.
- Допускаются любые символы, включая кириллицу (в заголовке передаются в URL-кодировке).

Сбросить забытый пароль:

```bash
docker exec -it -e BAO_ADDR=http://127.0.0.1:8200 openbao sh -c 'bao login && bao kv put secret/npm-dashboard/admin password=НОВЫЙ_ПАРОЛЬ'
```

Home перечитывает пароль из OpenBao не реже раза в минуту.

## Данные NPM

- Локальная база открывается только на чтение, поле `meta` (ключи DNS-провайдеров) не читается и не отдаётся в API.
- Для удалённых NPM используйте отдельную учётную запись с минимальными правами.

## Иконки

- Сервер ищет иконки только для сайтов из списка — произвольный адрес через `/api/icon` запросить нельзя.
- Ответ проверяется по сигнатуре: отдаются только изображения.
- SVG отдаётся с `Content-Security-Policy: sandbox` — скрипты внутри не выполняются.

## Рекомендации

- Не публикуйте Home в интернет без дополнительной защиты: поставьте в NPM список доступа (Access List) или авторизацию.
- Публикуйте через HTTPS, чтобы пароль администратора не передавался открытым текстом.
- Порт OpenBao оставьте закрытым (`127.0.0.1`), как в поставляемом compose-файле.
