# Возможности

## Карточки и меню

- **Избранное** — сайты со звёздочкой, всегда первыми в списке.
- **Все сайты**, **Свои сайты**, разделы по **источникам** (если их несколько) и по **доменам**.
- Сверху — счётчики: всего, включено, с HTTPS, показано. Режимы **Плитка** и **Список** запоминаются в браузере.
- Изменённые в NPM карточки подсвечиваются, внизу появляется уведомление «добавлено / изменено / удалено».
- Меню сворачивается до иконок (кнопка `«` внизу), на телефоне выезжает слева.
- Точка внизу меню: зелёная — поток событий подключён, жёлтая — переподключение, красная — ошибка источника.

## Поиск

Строка поиска получает фокус при открытии страницы.

| Действие | Результат |
|---|---|
| Ввод текста | Фильтрует карточки по названию, доменам, адресу назначения, описанию и группе |
| `Enter` | Ищет в выбранной поисковой системе; если введён адрес (`example.com`, `http://…`) — открывает его |
| `Ctrl`+`Enter` | Открывает первую найденную карточку |
| `Esc` | Очищает строку |
| `/` | Ставит фокус в строку поиска с любого места страницы |

Поисковая система выбирается слева от строки и запоминается в браузере. По умолчанию — та, что указана в настройках.
Свои поисковики добавляются в **Настройки → Общие**.

## Свои сайты

Кнопка **+ Свой сайт**: название, адрес (`http://` или `https://`), группа (можно выбрать домен из NPM), описание
и иконка (необязательно). Изменить или удалить — кнопка ✎ на карточке.

## Иконки сайтов

Иконку ищет сервер, по порядку:

1. адрес иконки, указанный у своего сайта;
2. `<link rel="icon">` и `apple-touch-icon` на главной странице сайта (сначала SVG, затем растровые — чем крупнее, тем лучше, до 256 px);
3. иконки из веб-манифеста;
4. `/favicon.ico`.

Сначала сервер пробует публичный адрес сайта. Если он с сервера недоступен (например, роутер без hairpin NAT),
запрос идёт напрямую на бэкенд хоста NPM с нужным заголовком `Host`; редиректы бэкенда на свой домен переписываются.
Найденные иконки кэшируются на 24 часа, ненайденные — на час. Если сервер ничего не нашёл, браузер напоследок пробует
`/favicon.ico` сам; если и это не вышло — показывается буква на цветном фоне.
