# Установка

Требования: Docker 24+ с Compose v2. Образ собран для `linux/amd64` и `linux/arm64`.

## Из релиза (рекомендуется)

```bash
curl -L https://github.com/sbrw-evc/Home/releases/download/v1.0.0/home-1.0.0-deploy.tar.gz | tar xz
cd home-1.0.0
cp .env.example .env
```

В `.env` укажите:

- `NPM_DATA_DIR` — путь к каталогу `data` локального Nginx Proxy Manager, тот, что у NPM смонтирован как `/data`
  (например, `/data/compose/1/data`). Если локального NPM нет, оставьте как есть: тогда источники добавляются в настройках.
- `HOME_PORT` — порт страницы на хосте (по умолчанию `8088`).

### Вариант А: OpenBao рядом с Home

```bash
./openbao/setup.sh
docker compose -f docker-compose.yml -f docker-compose.openbao.yml up -d
```

`setup.sh` запускает OpenBao, инициализирует и распечатывает его, создаёт политику и AppRole, прописывает `BAO_*` в `.env`
и генерирует пароль администратора. Подробнее — [[OpenBao]].

> **Важно:** сохраните содержимое `/root/openbao-init.json` (ключ распечатки и root-токен) в менеджере паролей и удалите файл с сервера.

### Вариант Б: свой OpenBao

Заполните в `.env` `BAO_ADDR` и `BAO_ROLE_ID`/`BAO_SECRET_ID` (или `BAO_TOKEN`), настройте политику по [[OpenBao]] и запустите:

```bash
docker compose up -d
```

### Вариант В: без OpenBao

Задайте `ADMIN_PASSWORD` в `.env` и запустите `docker compose up -d`. Работают локальный NPM, свои сайты, избранное и поиск;
**удалённые NPM добавить нельзя** — их пароли хранятся только в OpenBao.

## Первый вход

1. Откройте `http://<хост>:8088`.
2. Если смонтирована база локального NPM, источник «Локальный NPM» добавится автоматически.
3. Откройте **Настройки** (`#/settings`) — понадобится пароль администратора.
   При установке через `setup.sh` его можно узнать так:

   ```bash
   docker exec -it -e BAO_ADDR=http://127.0.0.1:8200 openbao sh -c 'bao login && bao kv get -field=password secret/npm-dashboard/admin'
   ```

   Затем смените его в карточке **Безопасность**.

## Из исходников

```bash
git clone https://github.com/sbrw-evc/Home.git && cd Home
cp .env.example .env
docker compose up -d --build
```

## За Nginx Proxy Manager

Заведите в NPM прокси-хост на `http://<хост>:8088`. Поток событий `/api/events` работает через NPM без дополнительной настройки:
приложение отправляет заголовок `X-Accel-Buffering: no`, который отключает буферизацию в nginx.

## Обновление

```bash
sed -i 's/^HOME_VERSION=.*/HOME_VERSION=1.0.0/' .env   # нужная версия
docker compose pull && docker compose up -d
```

Настройки, свои сайты, избранное и кэш иконок лежат в `./config` и переживают обновление.
Логины и пароли — в OpenBao.
