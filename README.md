# NPM main page

SPA-страница с карточками всех сайтов из [Nginx Proxy Manager](https://nginxproxymanager.com/).

- Читает базу NPM (`database.sqlite`) **только на чтение**. Поле `meta`, где хранятся ключи DNS-провайдеров, не читается.
- Обновляется на лету через Server-Sent Events: если в NPM добавить, изменить или удалить хост, карточки поменяются за пару секунд без перезагрузки страницы. Если SSE недоступен, страница опрашивает сервер.
- Группировка по доменам в боковом меню (hash-роутинг), поиск (горячая клавиша `/`), режимы «плитка» и «список», светлая и тёмная тема, мобильная вёрстка.
- Без зависимостей: Python 3 stdlib + vanilla JS.

## Запуск

В `docker-compose.yml` укажите путь к каталогу `data` вашего NPM (тот, что смонтирован в контейнер NPM как `/data`):

```yaml
volumes:
  - /path/to/npm/data:/npm:ro
```

```bash
docker compose up -d --build
```

Страница будет доступна на `http://<host>:8088`.

## Настройки (переменные окружения)

| Переменная      | По умолчанию            | Описание                                 |
|-----------------|-------------------------|------------------------------------------|
| `TITLE`         | `Мои сервисы`           | Заголовок страницы                       |
| `SHOW_DISABLED` | `true`                  | Показывать выключенные хосты             |
| `POLL_SECONDS`  | `2`                     | Как часто проверять изменения базы       |
| `NPM_DB`        | `/npm/database.sqlite`  | Путь к базе внутри контейнера            |
| `PORT`          | `8088`                  | Порт                                     |

## API

- `GET /api/hosts` — список хостов (JSON)
- `GET /api/events` — поток SSE, событие `hosts` при каждом изменении
- `GET /health` — проверка работоспособности

Работает только с SQLite-базой NPM (вариант по умолчанию). Если стоит за прокси, отключите буферизацию для `/api/events` (заголовок `X-Accel-Buffering: no` приложение уже отправляет).
